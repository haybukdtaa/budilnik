# Сервер «Проснись»: что нужно, чтобы подключить

Приложение уже умеет всё общение с сервером (`Prosnis/Social/HTTPBackend.swift`). Контракт — `server/openapi.yaml`.
Чтобы включить сервер, нужно сделать три вещи:

1. Реализовать методы из `openapi.yaml` (список ниже).
2. Указать адрес в `Prosnis/Core/AppConfig.swift`: `static let serverURL: URL? = URL(string: "https://api.ваш-домен.ru")`.
3. Заполнить данные оператора в `Prosnis/Domain/LegalTexts.swift` (`LegalOperator`) и показать тексты юристу.

Пока `serverURL == nil`, приложение работает только на телефоне; согласия, документы и привязка почты уже встроены.

> Это не юридическая консультация. Закон меняется (152-ФЗ правился в 2025 году): перед запуском сверьте раздел «Закон» с юристом.

## 1. Что реализует сервер

| Группа | Методы | Замечания |
|---|---|---|
| Вход | `POST /v1/auth/register` | userID + секрет из кода восстановления; секрет хранить зашифрованным (нужен для проверки подписи событий) |
| Почта | `POST /v1/auth/email/request`, `POST /v1/me/email/verify`, `DELETE /v1/me/email`, `POST /v1/auth/email/restore` | код из 6 цифр, 10 минут, 5 попыток; ответ всегда одинаков, есть почта в базе или нет |
| Согласия | `PUT/GET /v1/me/consents`, `GET /v1/legal/versions` | журнал согласий хранить, не перезаписывать; отзыв — применять (см. ниже) |
| Данные | `GET /v1/me/backup`, `GET /v1/me/export`, `DELETE /v1/me`, `POST /v1/sync`, `GET /v1/time` | выгрузка = право на получение копии; удаление — полное |
| Друзья и сообщество | `/v1/friends*`, `/v1/friend-requests*`, `/v1/invites*`, `/v1/rooms*`, `/v1/conversations/*`, `/v1/gardens*`, `/v1/leaderboards/*`, `/v1/stats/global`, `/v1/pair-challenges`, `/v1/me/status`, `/v1/me/missed`, `/v1/witness-notices`, `/v1/me/rewards`, `/v1/me/water` | приватность фильтровать на сервере, на стороне зрителя |
| Деньги | события утра (`wakeEvent` в `/v1/sync`), блокировка и списание по таймеру | описано в начале `openapi.yaml`; платёжный провайдер выберете сами |

Как сервер обязан реагировать на отзыв согласий (приходит в `PUT /v1/me/consents`):

- `personalData: false` — прекратить обработку, удалить данные аккаунта не позже чем через 30 дней (записи журнала согласий остаются);
- `specialData: false` — удалить все данные о намазе (`isPrayer`, модуль `prayer`, статусы Фаджра), не принимать новые;
- `distribution: false` — убрать человека из таблиц, комнат и клубов не позже чем через 3 рабочих дня;
- `terms: false` — закрыть серверные возможности для аккаунта (удаление данных — по запросу).

Восстановление по почте (устройство получает свой секрет, код из 16 слов не трогается):
`email/request(purpose=restore)` → письмо с кодом → `email/restore(email, code, secret)` → сервер добавляет новый секрет устройства
к найденному аккаунту и отдаёт прежний `userID`, токен и номер → приложение использует этот токен сразу и вызывает `backup`.

## 2. Закон (РФ): что сделать до запуска

**Оператор персональных данных.** Это тот, кто запускает сервер: ИП, самозанятый (проверьте, можно ли) или организация.
Реквизиты — в `LegalOperator` (`LegalTexts.swift`); пока там заглушки в квадратных скобках, в приложении виден жёлтый «Черновик».

**152-ФЗ «О персональных данных»:**

- Уведомление Роскомнадзора о начале обработки (ст. 22) — до запуска, через портал pd.rkn.gov.ru. Трансграничной передачи нет: серверы и почта в РФ, поэтому уведомление по ст. 12 не нужно, пока вы ничего не передаёте за границу.
- Локализация (ст. 18, ч. 5): первичная запись и хранение ПДн граждан РФ — в базах на территории РФ. Хостинг: Яндекс Облако, Selectel, VK Cloud, Timeweb и т. п. Почту с кодами отправлять российским сервисом (Unisender Go, Mail.ru для бизнеса, Яндекс Postbox). Не использовать Firebase, Google Analytics, зарубежные сервисы сбоев и рассылок для данных пользователей.
- Политика обработки опубликована на общедоступной странице (ст. 18.1) — адрес в `LegalOperator.site`, он же нужен в App Store Connect. Тексты уже в приложении (`LegalTexts.swift`), положите на сайт те же.
- Согласие (ст. 9) — конкретное, информированное, осознанное, отдельная галочка без предустановки; с 1 сентября 2025 года его оформляют отдельным документом, а не внутри оферты или политики. В приложении так и сделано: пять отдельных согласий, пользовательское соглашение отдельно.
- Особая категория (ст. 10): данные о намазе — сведения о религиозных убеждениях. Отдельное согласие `specialData`, без него данные остаются на телефоне. Данные о лекарствах (здоровье) на сервер не уходят никогда: так и оставьте.
- Распространение (ст. 10.1): таблицы, комнаты, клубы показывают данные неограниченному кругу — отдельное согласие `distribution`; требование прекратить распространение исполнять в течение 3 рабочих дней.
- Права человека (ст. 14, 20, 21): копия данных — `GET /v1/me/export` и кнопка в приложении; уточнение — в профиле; удаление — в Профиль → Данные; отзыв — в Профиль → Документы и согласия. На письма отвечать за 10 рабочих дней, на удаление и прекращение обработки — до 30 дней.
- Ответственный за организацию обработки (ст. 22.1) и внутренние документы: положение об обработке, перечень ПДн, модель угроз, регламент ответа на запросы, журнал доступа. Определить уровень защищённости (постановление № 1119): из-за особой категории он выше минимального.
- Утечки: уведомить Роскомнадзор в течение 24 часов, итоги расследования — в течение 72 часов (ст. 21, ч. 3.1). Подготовьте план действий заранее.
- Безопасность: TLS 1.2+, почта и секреты зашифрованы в базе, хеши для поиска, доступ по ролям, шифрованные копии, логи без лишних ПДн (IP не дольше 30 дней).

**Другие требования:**

- Возраст: обязательства и чаты только с 18 лет (в приложении переключатель и проверка; серверу стоит повторять проверку по `isAdult`).
- Пользовательский контент (чаты, клубы): модерация, жалоба на сообщение, блокировка человека — всё есть в приложении; сервер должен хранить жалобы и реагировать в разумный срок (по правилам App Store, пункт 1.2, — не дольше суток на серьёзные). Удалять незаконный контент по требованию уполномоченных органов.
- Платежи и обязательства: приём денег через российского платёжного провайдера, кассовые чеки (54-ФЗ), публичная оферта, порядок возврата, согласие на списание. Это отдельный комплект документов; он не входит в текущие тексты (там только условия обязательства `StakeTerms`).
- Реклама: рассылки новостей — только по отдельному согласию `marketing` (ФЗ «О рекламе»); приложение уже спрашивает его отдельно и по умолчанию отключено.

**App Store:** адрес политики конфиденциальности; карточка «Конфиденциальность приложения» (контактные данные — почта, идентификаторы, пользовательский контент, привязанные к человеку); удаление аккаунта внутри приложения (есть); правила для пользовательского контента (есть: жалоба, блок, соглашение).

## 3. Рекомендации по устройству

- База: PostgreSQL. Часы сервера — единственный источник времени для блокировок и списаний (`GET /v1/time`).
- События утра принимаются только с подписью HMAC (секрет аккаунта); время получения решает, а не время в событии.
- Ограничения частоты: вход и письма — по IP и по адресу; чат — по пользователю.
- Идемпотентность: все записи принимают повтор (`id`), журнал согласий — только добавление.
- Резервные копии шифровать и хранить не дольше 30 дней (иначе удаление данных не будет полным).
- Версия документов: `GET /v1/legal/versions`. Когда меняется любой текст, повышайте `LegalVersion.current` в приложении — согласия спросятся заново.
